# Changelog

## 4.1.0 — Visual Polish
- Reworked window shell, header, sidebar, tabs, sections, dialogs, notifications, and context surfaces for a more polished hierarchy.
- Added layered depth, gradients, accent glow, status pills, active navigation indicators, badges, and page descriptions.
- Added animated hover/press states and responsive UI density.
- Added theme roles for stronger text, soft borders, deeper surfaces, and stronger accents.
- Added visual `SetSubtitle`, `SetStatus`, `ApplyResponsive`, and `OnThemeRefresh` hooks.
- Scope intentionally limited to UI presentation and interaction feel.


## 4.0.0

- Rebuilt the modular core around a real public API.
- Added 60+ documented library capabilities.
- Added broad control/data/layout/feedback coverage.
- Added connection tracking and cleanup.
- Added theme role repainting and custom theme registration.
- Added persistent configuration with graceful fallback.
- Added reactive state management.
- Added responsive device capabilities.
- Added multi-window management, focus, minimize, maximize, restore, drag, resize, and visibility controls.
- Replaced placeholder component modules with working metadata/creator descriptors.
- Replaced every placeholder source URL with the canonical GitHub raw loader.
