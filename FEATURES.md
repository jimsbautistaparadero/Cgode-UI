# Cgode UI Feature Matrix

| Area | Included |
| --- | --- |
| Controls | 40+ reusable control/data primitives |
| Windows | Multi-window, drag, resize, minimize, maximize, restore, center, focus |
| Input | Mouse, touch, keyboard, gamepad detection, key capture, global bindings |
| Themes | Dark, Light, custom registration, live repaint |
| State | Reactive store, subscriptions, snapshots, updates |
| Config | JSON helpers, persistent file mode, memory fallback |
| Data | Tables, grids, lists, activity/timeline views |
| Visualization | Sparkline and bar primitives |
| Feedback | Toasts, notifications, dialogs, loading, errors, empty states |
| Layout | 11 layout primitive entry points |
| Extensibility | Component index, metadata, public component lookup |
| Reliability | Connection tracking, module fetch caching, argument normalization |
